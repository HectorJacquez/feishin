# Feishin (Hedgy fork)

A personal fork of [Feishin](https://github.com/jeffvli/feishin) with visual customizations I use daily with my Navidrome server.

## What I changed

**Theme engine and shape packs** - 12 custom color themes (Game Boy, Aero, Midnight, etc.) and five CSS shape packs that restyle the UI: Aero glass, CRT scanlines, Retro, Zine, and a set of type packs with custom fonts. Themes are hot-swappable from Settings.

**Canvas clips** - A fullscreen mode that plays looping video art behind the album cover while music plays, fetched from a configurable server URL in settings.

**Visualizer overlays** - The Butterchurn (Milkdrop) and AudioMotion visualizers can overlay the fullscreen player and the canvas view, with controls for opacity and blend mode.

**Popout panel** - A detachable mini-player window that stays on top, synced to the main window's playback state.

**Download playlist action** - Right-click a playlist to download it as a folder.

**Type packs** - Five font options (Courier Prime, Press Start 2P, Quicksand, VT323, system default) that apply globally through the shape system.
